# Fitness Academia - Sistema Web MVC

Sistema web acadêmico para gestão de academia, desenvolvido com HTML, CSS e JavaScript.

## Login de teste

E-mail: admin@academia.com  
Senha: 123456

## Funcionalidades

- Tela de login
- Dashboard inicial
- Cadastro de alunos
- Cadastro de planos
- Controle de pagamentos
- Cadastro de treinos
- Validação de e-mail
- Máscara de telefone
- Mensagens Toast
- Confirmação visual de exclusão de aluno
- Layout responsivo para celular
- Armazenamento com LocalStorage

## Arquitetura MVC

O projeto foi organizado utilizando o padrão MVC:

- Model: manipulação dos dados e LocalStorage
- View: páginas HTML e elementos da interface
- Controller: regras de interação entre tela e dados

## Como executar

1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code.
3. Use a extensão Live Server.
4. Abra o arquivo index.html.
5. Faça login com o usuário de teste.
